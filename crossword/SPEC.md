# もりのクロスワード 仕様・実装計画

## 1. コンテンツ概要

- コンテンツ名: もりのクロスワード
- カテゴリ: こくご・ことば
- 形式: たて・よこの問題を解き、最後にキーワードを見つけるクロスワードパズル
- 初期対象: 小学1〜2年生
- 将来の対象: 小学3〜4年生、小学5〜6年生、英語
- ゲームID: `word_crossword`
- 報酬方式: タイプD（成績・到達度連動ポイント）

問題を無限に自動生成する方式ではなく、語彙や交差、ヒントの分かりやすさを確認した固定ステージを用意する。

## 2. 基本の遊び方

1. コンテンツを開くと、ユーザー・学年レベル・ステージの選択画面を表示する。
2. ユーザーを選び、挑戦するレベルとステージを選ぶ。
3. 「このステージで はじめる」を押してゲームを開始する。
4. 「よこの かぎ」または「たての かぎ」から問題を選ぶ。
5. ランダムに並んだひらがなの文字カードから、答えを順番に選ぶ。
6. 「こたえあわせ」を押す。
7. 正解すると、クロスワードのマスが確定して5ポイントたまる。
8. すべての小問に正解すると、キーワード入力が開放される。
9. 番号の付いたマスを番号順に読み、最後のキーワードを入力する。
10. キーワードに正解すると、さらに30ポイントたまる。
11. クリア時は、最初に選択したユーザーへポイントを付与する。

途中で「おわる」を選んだ場合も、その時点で正解済みの小問ぶんのポイントを受け取れる。

## 3. ポイント仕様

- 小問1問正解: 5ポイント
- ステージ1の小問数: 6問
- 小問全問正解: 30ポイント
- 最終キーワード正解: 30ポイント
- ステージ1の最大獲得ポイント: 60ポイント

小問の正解時には画面内の獲得ポイントだけを更新する。既存ポイントへの加算は、最初に選択したユーザーに対して、次のどちらかのタイミングでまとめて行う。

- 最終キーワード正解後に「ポイントを もらう」を選んだとき
- 途中で「おわる」を選び、現在のポイントを受け取ったとき

ポイント付与には `ranking.js` の `addPoints()` を使用する。プレイ履歴は `savePlayLog()` で保存し、ゲームIDに `word_crossword` を指定する。

同一プレイ内で二重に受け取れないようにする。

## 4. 保存仕様

- 小問ごとの正解・入力途中の状態は保存しない。
- ページを開き直した場合、小問は最初から始まる。
- ステージ全体のクリア記録だけを、ユーザー別・ステージ別に `localStorage` へ保存する。
- 保存キー: `papan_crossword_progress_v2`

クリア済みステージは、選択したユーザーごとにステージ選択画面へ表示する。

最後に選択したユーザーは `papan_crossword_last_user` に保存する。次回も選択画面自体は必ず表示し、保存したユーザーを初期選択する。

## 5. 問題と盤面の設計原則

### 5.1 小学生向け表記

- 問題文は短く、具体的な場面が思い浮かぶ文章にする。
- 画面に表示する漢字には必ず `<ruby>` と `<rt>` でルビを付ける。
- マスに入力する答えは、原則としてひらがなにする。
- 小学1〜2年生が日常や学校で触れる語彙を中心にする。
- 難しい同音異義語や、説明が複数の答えに当てはまる問題は避ける。

### 5.2 クロスワードとしての品質

- たて・よこの答えが正しい文字で交差すること。
- 問題文だけでも答えを考えられ、交差文字が適度な助けになること。
- 盤面に意図しない連続マスや、問題に含まれない単語ができないこと。
- 同じステージ内で、似すぎた問題や同じ意味の問題を重ねないこと。
- 全問を解く意味が残るように盤面とキーワードを設計すること。

### 5.3 最終キーワードの品質基準

- 最終キーワードを小問の答えと同じ単語にしない。
- 1つの小問から複数のキーワード文字を取り出さない。
- キーワード文字は、できるだけ別々の小問から1文字ずつ集める。
- 1問を解いただけでキーワードの大部分が判明する配置を避ける。
- キーワードは対象学年が知っている、前向きで分かりやすいことばにする。
- キーワードを推測できても、全小問正解までは最終入力を開放しない。

ステージ1では「なかよし」の4文字を、別々の4問から1文字ずつ取得する。

## 6. 文字カード仕様

- 各問題の正解に必要な文字を必ず含める。
- 正解文字以外の文字も加え、原則14文字程度を表示する。
- 文字カードは問題を表示するたびにランダム配置する。
- 正解の単語が左から順番どおりに並ばないようにする。
- 同じ文字を複数回使う答えにも将来対応できるよう、文字カードは使用後も消さない。
- 「ひとつ けす」で、最後に入力した未確定文字を戻せるようにする。
- すでに正解した交差文字は固定し、別の問題から消せないようにする。

## 7. ステージ1

### 対象

- 小学1〜2年生
- 6×6マス
- よこ3問、たて3問

### 小問

| 方向 | 番号 | 答え | 問題の内容 |
|---|---:|---|---|
| よこ | 1 | なみ | 海で寄せてくる波 |
| よこ | 2 | おべんとう | 箱に詰めて外で食べるもの |
| よこ | 3 | いろ | 赤・青・黄色などのまとめ方 |
| たて | 1 | みかん | 皮をむいて食べる果物 |
| たて | 2 | おはよう | 朝の最初のあいさつ |
| たて | 3 | うしろ | 「前」の反対の場所 |

### 最終キーワード

- 答え: なかよし
- 「な」: よこ1から取得
- 「か」: たて1から取得
- 「よ」: たて2から取得
- 「し」: たて3から取得

各キーワード文字は、他の問題と交差していない単独のマスから取得する。

## 8. キャラクターとデザイン

- エゾリスの「ヒー」とハリネズミの「アン」をタイトル付近の案内役にする。
- くまの「ピッピ」を最終キーワードの案内役にする。
- キャラクター画像は答えのマスや問題文を隠さない位置に置く。
- 既存のWebP画像を使用し、ぱぱん式の水彩・色鉛筆風の雰囲気に合わせる。
- ボタンはタップしやすい大きさと3D風の押し心地を持たせる。
- スマートフォンとパソコンの両方で、盤面と問題を読みやすくする。

## 8.1 ステージ2

### 対象

- 小学1〜2年生
- 6×6マス
- よこ3問、たて3問

### 小問

| 方向 | 番号 | 答え | 問題の内容 |
|---|---:|---|---|
| よこ | 1 | いす | 座るときに使うもの |
| よこ | 2 | かくれんぼ | 隠れる人と探す人に分かれる遊び |
| よこ | 3 | そら | 雲や太陽が見える上の方 |
| たて | 1 | すみれ | 紫色の小さな花 |

| たて | 3 | ぼくら | おもに男の子が自分たちを指すことば |

### 最終キーワード

- 答え: やくそく
- 「や」: たて2から取得
- 1つ目の「く」: よこ2から取得
- 「そ」: よこ3から取得
- 2つ目の「く」: たて3から取得

ステージ1と同様に、小問の答えと最終キーワードは重複させず、1問から取得するキーワード文字は1文字までとする。

## 9. ファイル構成

```text
crossword/
├── index.html   # 画面構造
├── style.css    # クロスワード専用デザイン
├── stages.js    # ステージ・問題・盤面・キーワードのデータ
├── app.js       # 入力、採点、進行、ポイント、保存処理
└── SPEC.md      # 本仕様と実装計画
```

ステージ追加時は、基本的に `stages.js` にデータを追加し、共通処理は `app.js` にまとめる。ステージ数や学年が大きく増えた場合は、次のようにデータファイルを分割する。

```text
crossword/
└── stages/
    ├── japanese_grade_1_2.js
    ├── japanese_grade_3_4.js
    ├── japanese_grade_5_6.js
    └── english_basic.js
```

## 10. 今後の実装計画

### フェーズ1: 小学1〜2年生版

1. ステージ1の操作性と問題難易度を確認する。
2. ステージ3の盤面と問題を作成する。
3. 準備中のステージ3カードを、実装完了後に選択可能へ切り替える。
4. ステージごとにキャラクターの配置やテーマを変える。

ステージ2・3でも、小問数とポイント配分は当面ステージ1に合わせる。盤面の大きさは問題語彙に応じて6×6〜8×8程度を検討する。

### フェーズ2: 小学3〜4年生版

- 少し長い名詞、動詞、形容詞を追加する。
- 反対語、仲間のことば、様子を表すことばを問題に取り入れる。
- 問題文の読解が必要なヒントを少し増やす。
- 盤面は7×7〜9×9程度を検討する。
- 学年選択画面を追加する。

### フェーズ3: 小学5〜6年生版

- 熟語、慣用表現、ことわざにつながる語彙を追加する。
- 複数の意味を比べて考える問題を取り入れる。
- 長い答えや交差数を増やす。
- 難易度に応じたヒント機能を検討する。

### フェーズ4: 英語版

- 最初は小文字の英単語と身近な語彙を使用する。
- 問題文は日本語、答えは英語から開始する。
- 将来は問題文も英語に切り替えられるようにする。
- 日本語版と同じ盤面処理を使い、文字カードだけアルファベットへ切り替える。
- フォニックスやカテゴリー別単語への展開を検討する。

## 11. ステージ追加時の確認項目

- [ ] 対象学年に合った語彙か
- [ ] 問題文の漢字すべてにルビがあるか
- [ ] 答えが一意に決まる問題文か
- [ ] たて・よこの交差文字が一致しているか
- [ ] 盤面からはみ出す答えがないか
- [ ] 意図しない単語や連続マスがないか
- [ ] 正解文字が文字カードにすべて含まれているか
- [ ] 文字カードがランダム配置されるか
- [ ] 最終キーワードが小問の答えと重複していないか
- [ ] 1問からキーワード文字を2文字以上取っていないか
- [ ] 全小問を解く意味が残る構成か
- [ ] 途中終了時のポイントが正しいか
- [ ] 最大獲得ポイントが仕様どおりか
- [ ] スマートフォンで文字やボタンが重ならないか
- [ ] `service-worker.js` のキャッシュ対象とバージョンを更新したか
